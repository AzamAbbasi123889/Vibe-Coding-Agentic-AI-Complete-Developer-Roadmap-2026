# Glossary

| Term | Meaning |
|------|---------|
| Agent | An LLM in a loop that can use tools (read files, run commands) |
| API | Interface for programs to talk to each other |
| Context window | The text a model can consider at once |
| Diff | The changes between two versions of code |
| Hallucination | Confident but false output from a model |
| LLM | Large language model |
| MCP | Model Context Protocol, an open standard for connecting tools to AI apps |
| Prompt | The instructions and context you give a model |
| Prompt injection | Malicious or accidental instructions hidden in input that steer a model |
| RAG | Retrieval-augmented generation: fetch relevant documents and give them to the model |
| Rules file | Project instructions loaded automatically by an AI tool |
| Token | A chunk of text the model reads or writes (roughly a word fragment) |
| Vibe coding | Building software by describing intent to an AI and iterating on results |
| Worktree | A Git feature that checks out multiple branches in separate folders |
