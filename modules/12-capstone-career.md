# Module 12: Capstone and Career

## 12.1 Capstone project
Choose one from `projects/` (or propose your own) and deliver:

1. `SPEC.md` written **before** coding
2. A rules file for your AI tool
3. A working, deployed app with a public URL
4. Automated tests for core logic
5. A security review (Module 09 checklist)
6. A README with screenshots, setup steps, architecture notes, and a **"What the AI got wrong"** section
7. A 3 to 5 minute demo video or written walkthrough

### Grading rubric (self-assess, 0 to 4 each)
| Criterion | 0 | 4 |
|-----------|---|---|
| Spec quality | none | clear scope, done-criteria, non-goals |
| Working software | broken | deployed, stable |
| Code understanding | cannot explain | can explain every major part |
| Testing | none | meaningful tests, edge cases |
| Security | ignored | checklist completed, secrets safe |
| Documentation | minimal | anyone can run and understand it |

## 12.2 Portfolio tips
- Pin your best 3 to 6 repos
- Every repo: clear README, screenshot or GIF, live link, tech list
- Write short posts about lessons learned (what broke, how you fixed it)
- Show your process: specs, prompts that worked, reviews you performed

## 12.3 How employers view AI skills
Teams value people who can ship quickly **and** reason about correctness. Demonstrate:
- You review and test AI output
- You understand architecture trade-offs
- You can debug without the AI when needed
- You communicate clearly in writing

## 12.4 Keep learning
- Strengthen fundamentals: data structures, algorithms, SQL, networking basics
- Learn one frontend and one backend framework properly
- Study system design at a basic level
- Read other people's code on GitHub
- Follow official docs and changelogs of your tools
- Practise without AI sometimes, such as coding problems and small utilities, so your skills stay sharp

## 12.5 Final reflection
In your journal answer:
1. Where did AI save me the most time?
2. Where did it cost me time?
3. What is my personal review checklist?
4. What will I build next?

**Congratulations. Now go ship something.**
