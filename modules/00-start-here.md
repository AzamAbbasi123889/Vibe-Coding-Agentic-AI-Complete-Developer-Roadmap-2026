# Module 00: Start Here

## Goals
- Understand how the course works
- Set up a machine that is ready for AI-assisted coding

## How to study
1. **Read** the lesson once without a computer.
2. **Do** the exercise in `exercises/` immediately after.
3. **Commit** your work to your own GitHub repo. A green contribution graph is proof of learning.
4. **Reflect** for two minutes: what did the AI get wrong today?

## Setup checklist

| Item | Why | Check |
|------|-----|-------|
| A computer with internet | Most tools are cloud-backed | [ ] |
| Git installed | Version control is your undo button | `git --version` |
| GitHub account | Hosting, sharing, deployment | [ ] |
| Node.js LTS | Needed for many AI tools and web apps | `node -v` |
| Python 3.10+ | Needed for scripts, APIs, ML projects | `python --version` |
| VS Code (or another editor) | Reading and editing code | [ ] |
| One AI coding tool account | Start with a free tier | [ ] |

## Your course repository

Create a folder called `my-vibe-journal`:

```bash
mkdir my-vibe-journal && cd my-vibe-journal
git init
echo "# My Vibe Coding Journal" > README.md
git add . && git commit -m "Start journal"
```

Each week, add a markdown file: what you built, which prompts worked, which failed.

## Golden rules for the whole course

1. **You are the engineer.** The AI is a fast, tireless junior developer who is sometimes confidently wrong.
2. **Commit before every big AI change.** You can always roll back.
3. **Run the code.** Never trust code you have not executed.
4. **Read the diff.** If you cannot explain a change, ask the AI to explain it.
5. **Never paste secrets** (API keys, passwords) into prompts or commit them.
