# Project 4: Expense Dashboard

**Stack suggestion:** Next.js or React + FastAPI/Express + PostgreSQL (or SQLite to start)

## Requirements
- Add expenses, categories, recurring expenses
- Monthly and category charts
- CSV import and export
- Authentication with a mature provider or library
- Each user sees only their own data

## Milestones
1. Spec with data model diagram (ask AI for a Mermaid ER diagram, then review)
2. Backend and migrations
3. Auth and authorisation checks
4. Dashboard UI and charts
5. CSV import with validation (what about huge files or bad formats?)
6. Tests for totals and permissions
7. Deploy frontend + backend + database

## Review focus
Try to read another user's data by changing IDs in URLs. Fix anything that works.
