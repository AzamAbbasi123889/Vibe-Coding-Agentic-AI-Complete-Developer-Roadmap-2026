# Project 1: Habit Tracker

**Goal:** A web app to track daily habits and streaks.

## Requirements
- Add, edit, delete habits (name, color)
- 14-day grid, click to toggle a day
- Current streak and weekly completion %
- Light and dark mode, mobile friendly
- Data saved in the browser

## Milestones
1. Prompt the app builder with the spec
2. Fix three usability issues you find
3. Export to GitHub and read the generated code
4. Add tests for the streak calculation (ask the AI to extract it into a pure function)
5. Deploy and share the link

## Stretch
Add a backend and login. Then run the Module 09 security checklist.
